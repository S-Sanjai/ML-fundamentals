# 🤖 Scikit-learn Logistic Regression Model

This directory contains a powerful **Logistic Regression model** built with the `scikit-learn` library, a go-to tool for professional machine learning tasks. The model is trained to classify breast cancer tumors as **malignant** or **benign** based on imaging data.

---

## 📊 Model Performance

Our `scikit-learn` model achieves an impressive accuracy, demonstrating its effectiveness in this classification task.

- **🎯 Accuracy:** **97.37%**

---
